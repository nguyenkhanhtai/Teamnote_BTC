\section*{C++: cách dùng code}
\addcontentsline{toc}{section}{C++: cách dùng code}
\textbf{Chuẩn bị}: GNU C++17, thêm \texttt{\#include <bits/stdc++.h>} và \texttt{using namespace std;}. Chép struct/hàm trước \texttt{main}; mỗi listing có dòng \texttt{// Use:} minh họa khai báo và gọi. ID bắt đầu từ $0$, đoạn mảng $[l,r)$.

\textbf{Khai báo}: \texttt{Dinic flow(n);} tạo flow graph có $n$ đỉnh; \texttt{SegmentTreeBeats st(a);} dựng từ \texttt{vector<long long> a}. Dùng kiểu cụ thể; nếu cần kiểu khác, sửa dòng \texttt{using} hoặc kiểu dữ liệu của module. KD-tree đổi hằng \texttt{D} cho số chiều.

\textbf{Callback = hàm bạn viết}: truyền tên hàm, không cần lambda. \texttt{function<bool(const vector<int>\&)>} nghĩa là nhận tập ID và trả về đúng/sai. Dữ liệu riêng của bài có thể đặt ở biến toàn cục để hàm đọc.

\textbf{Khi include file nguồn}: dùng \texttt{notebook::graph::Dinic flow(n);} hoặc \texttt{using namespace notebook::graph;}. Nhóm khác: \texttt{data\_structure}, \texttt{tree}, \texttt{strings}, \texttt{dp}, \texttt{math}, \texttt{geometry}. PDF lược namespace/include; file nguồn giữ dependency.

\textbf{Kết quả}: kiểm tra \texttt{if (ans)} trước khi lấy \texttt{*ans} từ \texttt{optional}. Flow cập nhật residual graph; lần gọi sau trả phần flow tăng thêm. Wavelet dùng rank $k$ từ $0$, khoảng \emph{giá trị} khi đếm đóng hai đầu. Tên \texttt{g}, \texttt{cost}, \texttt{oracle} trong ví dụ là dữ liệu/hàm bạn cung cấp.
