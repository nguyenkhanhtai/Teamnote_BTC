// Complexity: O((N + Q) log N) amortized; O((N + Q) log^2 N) with Range Add
// Segment Tree Beats (Ji Driver Segment Tree) - Core Ideas & Principles

1. Core Concept & Motivation:
   - Target operations: Range Chmin (A[i] = min(A[i], x)), Range Chmax, Range Add, Range Sum.
   - Key Insight: A range chmin(x) only modifies elements strictly greater than x.
     By isolating the strictly maximum elements, we can update them in O(1) without
     affecting any other elements in the segment.

2. Maintained Node State:
   - max1: Strictly largest value in node range.
   - max2: Strictly second largest value (max2 < max1; -INF if all values equal).
   - cnt_max: Number of occurrences of max1 in node range.
   - sum: Sum of all elements in node range.
   - (Symmetrically maintain min1, min2, cnt_min if Range Chmax is also needed).
   - Lazy tags: lazy_add (additive shift), lazy_max (chmin bound).

3. The Three Update Conditions for Range Chmin(x):
   - Break Condition (Outside or No-Op):
     Node interval is disjoint from query interval, OR x >= max1.
     Action: Return immediately (no value in subtree can change).
   - Tag Condition (Direct O(1) Update):
     Node interval is fully inside query interval, AND max2 < x < max1.
     Action: Only the cnt_max elements equal to max1 decrease to x.
             sum -= cnt_max * (max1 - x); max1 = x; set lazy tag; return.
   - Recursion Condition (Multiple Values Affected):
     Node interval is fully inside query interval, BUT x <= max2.
     Action: Both max1 and max2 (and potentially others) change.
             Push down pending tags, recurse into both children, then pull/merge.

4. Maintenance Rules (Pull & Push):
   - Pull (Merge from children L, R):
     * sum = L.sum + R.sum
     * max1 = max(L.max1, R.max1)
     * cnt_max = sum of cnt_max of children having child.max1 == parent.max1.
     * max2 = largest value among {L.max1, L.max2, R.max1, R.max2} strictly less than max1.
   - Push Down (Lazy Propagation):
     * Additive tags apply to all elements (shift sum, max1, max2, min1, min2).
     * Chmin tag u.max1 only pushes to children with child.max1 > u.max1:
       child.sum -= child.cnt_max * (child.max1 - u.max1), child.max1 = u.max1.

5. Complexity & Potential Analysis:
   - Define potential Phi = total number of distinct values across all nodes in tree.
   - Each recursion into the 3rd case (x <= max2) forces at least two distinct values
     to merge into one, strictly decreasing Phi by >= 1.
   - Chmin/Chmax + Sum: amortized O((N + Q) log N).
   - Range Add creates at most O(log N) new distinct values -> amortized O((N + Q) log^2 N).

6. Common Extensions:
   - Range Divide (A[i] = floor(A[i] / d)): Convert to Range Add when
     max1 - floor(max1 / d) == min1 - floor(min1 / d), otherwise recurse.
   - Range Modulo (A[i] = A[i] % d): Break if max1 < d; otherwise recurse
     (each recursion strictly halves values >= d).
   - Historical Min/Max/Sum: Maintain historical max tag alongside current tag.
